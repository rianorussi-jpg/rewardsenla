# 008 · Cashback

Ejecuta `008-cashback.sql` después de 007. Convierte programas antiguos `points` a `cashback`, agrega movimientos `cashback` y `spend`, y crea `rewards_spend_cashback`.

En cashback `current_value` representa pesos MXN disponibles. `increment_value` es el monto predeterminado que se agrega por operación. El saldo puede gastarse total o parcialmente.
