# Fix notificaciones Apple Wallet

1. Ejecuta `015A-fix-apple-wallet-notifications.sql` en Supabase SQL Editor.
2. Reemplaza `apple-wallet-pass` por la versión incluida en este proyecto.
3. Reemplaza `wallet-sync` por la versión incluida en este proyecto.
4. Haz deploy del frontend en Vercel.

No hace falta borrar la tarjeta de Wallet si ya recibe actualizaciones de sellos.
